שאלה 7: פתרון מלא

טרפז, קטע אמצעים בטרפז ומשפטי תאלס

נוסח השאלה

בטרפז ABCD (AB ∥ CD) נתון AB = a ו־CD = b, כאשר b > a.

א. הנקודות M ו־N הן אמצעי השוקיים AD ו־BC. הוכיחו את משפט קטע האמצעים בטרפז: MN ∥ AB וגם MN = ½(a + b).

ב. נתון גם: הקטע MN חותך את האלכסון AC בנקודה E ואת האלכסון BD בנקודה F. הוכיחו ש־E אמצע AC וש־F אמצע BD, וחשבו באמצעות a, b את EF.

ג. נתון גם: האלכסונים AC ו־BD נחתכים בנקודה O. חשבו באמצעות a, b את היחס AO : OE.

ד. נתון גם: הנקודה P על AD והנקודה Q על BC מקיימות AP : PD = BQ : QC = a : b. הוכיחו שהנקודות P, O, Q על ישר אחד המקביל ל־AB, וחשבו באמצעות a, b את PQ.

ה. הוכיחו: PQ < MN.

א. הנקודות M ו־N הן אמצעי השוקיים AD ו־BC. הוכיחו את משפט קטע האמצעים בטרפז: MN ∥ AB וגם MN = ½(a + b).
מס׳טענהנימוק
1AM = MD, BN = NC, AB ∥ CD, AB = a, CD = bנתון
2K נקודת החיתוך של CM עם המשך BAבניית עזר: נמשיך את CM עד שיפגוש את המשך BA בנקודה K
3∠KAM = ∠CDMזוויות מתחלפות שוות: ישרים מקבילים וחותך יוצרים זוויות מתחלפות שוות כאן: AB ∥ CD (נתון) ו־AD חותך
4∠AMK = ∠DMCזוויות קודקודיות: זוויות קודקודיות שוות כאן: K, M, C על ישר אחד ו־A, M, D על ישר אחד
5△AMK ≅ △DMCחפיפה (ז.צ.ז): שתי זוויות והצלע שביניהן בשני משולשים שוות כאן: AM = MD (טענה 1), ∠KAM = ∠CDM (טענה 3), ∠AMK = ∠DMC (טענה 4)
6AK = DC = b וגם KM = MCצלעות מתאימות בשני משולשים חופפים: צלעות מתאימות בשני משולשים חופפים שוות כאן: △AMK ≅ △DMC (טענה 5)
7KB = KA + AB = b + aחיבור קטעים: אם נקודה על קטע, אורך הקטע שווה לסכום חלקיו כאן: A בין K ל־B
8MN ∥ KB, כלומר MN ∥ AB, וגם MN = ½·KB = ½(a + b) ∎משפט קטע האמצעים: קטע המחבר את אמצעי שתי צלעות במשולש מקביל לצלע השלישית ושווה למחציתה כאן: במשולש KBC: M אמצע KC (טענה 6) ו־N אמצע BC (טענה 1), ו־KB = a + b (טענה 7)
ב. נתון גם: הקטע MN חותך את האלכסון AC בנקודה E ואת האלכסון BD בנקודה F. הוכיחו ש־E אמצע AC וש־F אמצע BD, וחשבו באמצעות a, b את EF.
מס׳טענהנימוק
1AB = a, CD = b, b > a, E על MN ו־AC, F על MN ו־BDנתון
2MN ∥ DCסעיף א׳ (MN ∥ AB ו־AB ∥ CD)
3E אמצע AC וגם F אמצע BDמשפט הפוך למשפט קטע אמצעים: ישר העובר דרך אמצע צלע במשולש והמקביל לצלע שנייה, חוצה את הצלע השלישית כאן: במשולש ADC: M אמצע AD ו־ME ∥ DC (טענה 2); במשולש ABD: M אמצע AD ו־MF ∥ AB (סעיף א׳)
4ME = ½·DC = b/2 וגם MF = ½·AB = a/2משפט קטע האמצעים: קטע המחבר את אמצעי שתי צלעות במשולש מקביל לצלע השלישית ושווה למחציתה כאן: במשולש ADC: M, E אמצעי AD, AC; במשולש ABD: M, F אמצעי AD, BD (טענה 3)
5EF = ME − MF = (b − a)/2 ∎חיסור קטעים: אורך קטע שווה להפרש האורכים כשהנקודות על ישר בסדר ידוע כאן: MF < ME (טענה 4, כי a < b), ולכן F בין M ל־E
ג. נתון גם: האלכסונים AC ו־BD נחתכים בנקודה O. חשבו באמצעות a, b את היחס AO : OE.
מס׳טענהנימוק
1AB = a, והאלכסונים AC ו־BD נחתכים ב־Oנתון
2EF ∥ ABסעיף א׳ (MN ∥ AB), ו־E, F על MN
3EF = (b − a)/2סעיף ב׳
4AO/OE = BO/OF = AB/EFמשפט תאלס המורחב: ישרים נחתכים ושני ישרים מקבילים החותכים אותם יוצרים יחסים שווים בין הקטעים ובין הקטעים המקבילים כאן: AE, BF נחתכים ב־O ו־EF ∥ AB (טענה 2)
5AO : OE = AB : EF = a : (b − a)/2 = 2a : (b − a) ∎טענה 4, הצבת טענות 1, 3
ד. נתון גם: הנקודה P על AD והנקודה Q על BC מקיימות AP : PD = BQ : QC = a : b. הוכיחו שהנקודות P, O, Q על ישר אחד המקביל ל־AB, וחשבו באמצעות a, b את PQ.
מס׳טענהנימוק
1AB = a, CD = b, AP : PD = BQ : QC = a : bנתון
2AP/AD = BQ/BC = a/(a + b)חישוב (מטענה 1)
3AO/OC = BO/OD = AB/CD = a/bמשפט תאלס המורחב: ישרים נחתכים ושני ישרים מקבילים החותכים אותם יוצרים יחסים שווים בין הקטעים ובין הקטעים המקבילים כאן: AB ∥ CD, AC, BD נחתכים ב־O, ו־AB = a, CD = b (טענה 1)
4AO/AC = BO/BD = a/(a + b)חישוב (מטענה 3)
5AP/AD = AO/AC וגם BQ/BC = BO/BDשניהם שווים ל־a/(a + b) (טענות 2, 4)
6PO ∥ DC וגם QO ∥ DCמשפט תאלס ההפוך: אם ישר חותך שתי צלעות במשולש ומחלק אותן ביחס שווה מצד אותו קדקוד, הוא מקביל לצלע השלישית כאן: במשולש ADC ו־BDC (טענה 5)
7P, O, Q על ישר אחד המקביל ל־AB ∎דרך O עובר ישר אחד בלבד המקביל ל־DC (טענה 6), ו־DC ∥ AB
8PO/DC = AO/AC = a/(a + b) וגם OQ/DC = BO/BD = a/(a + b)משפט תאלס המורחב: ישר המקביל לצלע במשולש וחותך את שתי הצלעות האחרות, יוצר יחס שווה בין הקטעים על הצלעות לבין יחס הקטע המקביל לצלע כאן: במשולש ADC עם PO ∥ DC, ובמשולש BDC עם OQ ∥ DC (טענה 6), ו־AO/AC = BO/BD = a/(a + b) (טענה 4)
9PO = OQ = DC · a/(a + b) = b · a/(a + b) = ab/(a + b)הצבת DC = b (טענה 1) בטענה 8
10PQ = PO + OQ = ab/(a + b) + ab/(a + b) = 2ab/(a + b) ∎חיבור קטעים: אם נקודה על קטע, אורך הקטע שווה לסכום חלקיו כאן: O בין P ל־Q (טענה 7), ו־PO = OQ (טענה 9)
ה. הוכיחו: PQ < MN.
מס׳טענהנימוק
1AB = a, CD = b, b > aנתון
2MN = (a + b)/2 וגם PQ = 2ab/(a + b)סעיפים א׳ ו־ד׳
3MN − PQ = a + b2 − 2aba + bהצבת טענה 2
4= (a + b)²2(a + b) − 4ab2(a + b)הרחבה למכנה משותף 2(a + b): הכפלת השבר הראשון ב־(a + b)/(a + b) והשני ב־2/2
5= (a + b)² − 4ab2(a + b)חיסור שברים עם מכנה משותף
6= a² + 2ab + b² − 4ab2(a + b)נוסחת הכפל המקוצר (a + b)² = a² + 2ab + b²
7= (a − b)²2(a + b)a² − 2ab + b² = (a − b)² (נוסחת הכפל המקוצר)
8MN − PQ > 0, ולכן PQ < MN ∎b > a (טענה 1) ולכן (a − b)² > 0, ו־a + b > 0, ולכן המנה חיובית (טענה 7)

סיכום התוצאות

  • סעיף א׳: MN ∥ AB וגם MN = ½(a + b)
  • סעיף ב׳: E אמצע AC, F אמצע BD ו־EF = (b − a)/2
  • סעיף ג׳: AO : OE = 2a : (b − a)
  • סעיף ד׳: P, O, Q על ישר אחד המקביל ל־AB, ו־PQ = 2ab/(a + b)
  • סעיף ה׳: PQ < MN
