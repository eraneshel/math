שאלה 5: פתרון מלא

קטע אמצעים במרובע ושטח מרובע בעל אלכסונים מאונכים

נוסח השאלה

במרובע קמור ABCD הנקודות E, F, G, H הן אמצעי הצלעות AB, BC, CD, DA בהתאמה. נתון AC ⊥ BD, ונסמן AC = p ו־BD = q.

א. הוכיחו: EFGH מלבן.

ב. הביעו באמצעות p ו־q את היקף EFGH ואת שטחו.

ג. הוכיחו: שטח EFGH הוא חצי משטח ABCD.

ד. נתון p > q, היקף EFGH הוא 28 ושטחו 48. מצאו את p ואת q.

א. הוכיחו: EFGH מלבן.
מס׳טענהנימוק
1AE = EB, BF = FC, CG = GD, DH = HA, AC ⊥ BDנתון
2EF ∥ AC, HG ∥ AC וגם EF = HG = ½ACמשפט קטע האמצעים: קטע המחבר את אמצעי שתי צלעות במשולש מקביל לצלע השלישית ושווה למחציתה כאן: במשולש ABC: E, F אמצעי AB, BC; במשולש ADC: H, G אמצעי AD, DC (טענה 1)
3FG ∥ BD, EH ∥ BD וגם FG = EH = ½BDמשפט קטע האמצעים: קטע המחבר את אמצעי שתי צלעות במשולש מקביל לצלע השלישית ושווה למחציתה כאן: במשולש BCD: F, G אמצעי BC, CD; במשולש ABD: E, H אמצעי AB, AD (טענה 1)
4EFGH מקביליתמרובע עם זוג צלעות נגדיות שוות ומקבילות: מרובע שבו זוג צלעות נגדיות שוות ומקבילות הוא מקבילית כאן: EF ∥ HG, כי שניהם מקבילים ל־AC, ו־EF = HG (טענה 2)
5FG ⊥ ACישר המאונך לאחד משני ישרים מקבילים: ישר המאונך לאחד משני ישרים מקבילים מאונך גם לשני כאן: FG ∥ BD (טענה 3) ו־BD ⊥ AC (טענה 1)
6FG ⊥ EF, כלומר ∠EFG = 90°ישר המאונך לאחד משני ישרים מקבילים: ישר המאונך לאחד משני ישרים מקבילים מאונך גם לשני כאן: EF ∥ AC (טענה 2) ו־FG ⊥ AC (טענה 5)
7EFGH מלבן ∎מקבילית עם זווית ישרה: מקבילית שיש בה זווית ישרה היא מלבן כאן: EFGH מקבילית (טענה 4) ו־∠EFG = 90° (טענה 6)
ב. הביעו באמצעות p ו־q את היקף EFGH ואת שטחו.
מס׳טענהנימוק
1AC = p, BD = q, EFGH מלבןנתון וסעיף א׳
2EF = HG = p2 וגם FG = EH = q2סעיף א׳ (EF = HG = ½AC, FG = EH = ½BD) והצבת AC = p, BD = q (טענה 1)
3היקף EFGH = 2(EF + FG) = 2(p2 + q2)נוסחת היקף מלבן והצבת טענה 2
4היקף EFGH = p + q ∎חישוב (מטענה 3)
5שטח EFGH = EF · FGנוסחת שטח מלבן: אורך כפול רוחב (EFGH מלבן, טענה 1)
6שטח EFGH = p2 · q2 = pq4 ∎הצבת טענה 2 בטענה 5
ג. הוכיחו: שטח EFGH הוא חצי משטח ABCD.
מס׳טענהנימוק
1AC ⊥ BD, AC = p, BD = q, ונסמן ב־O את נקודת המפגש של האלכסוניםנתון וסימון
2BO ⊥ AC, DO ⊥ AC, ו־O בין B ל־DBD ⊥ AC (טענה 1), ו־O על BD: במרובע קמור נקודת המפגש של האלכסונים פנימית לשניהם
3SABC = ½·AC·BO וגם SACD = ½·AC·DOנוסחת שטח משולש: חצי מכפלת בסיס בגובה אליו. כאן: BO גובה ל־AC במשולש ABC, ו־DO גובה ל־AC במשולש ACD (טענה 2)
4SABCD = SABC + SACDחיבור שטחים: שטח צורה שווה לסכום שטחי חלקיה כאן: האלכסון AC מחלק את המרובע הקמור ABCD לשני המשולשים ABC, ACD
5SABCD = ½·AC·BO + ½·AC·DO = ½·AC·(BO + DO)הצבת טענה 3 בטענה 4 והוצאת גורם משותף ½·AC
6BO + DO = BD = qחיבור קטעים: אם נקודה על קטע, אורך הקטע שווה לסכום חלקיו כאן: O בין B ל־D (טענה 2), ו־BD = q (טענה 1)
7SABCD = ½·p·q = pq2הצבת AC = p (טענה 1) וטענה 6 בטענה 5
8SEFGH = pq4 = ½·pq2 = ½·SABCD ∎סעיף ב׳ (שטח EFGH) והצבת טענה 7
ד. נתון p > q, היקף EFGH הוא 28 ושטחו 48. מצאו את p ואת q.
מס׳טענהנימוק
1p > q, היקף EFGH = 28, שטח EFGH = 48נתון
2p + q = 28היקף EFGH = p + q (סעיף ב׳), והצבת הנתון (טענה 1)
3pq4 = 48שטח EFGH = pq4 (סעיף ב׳), והצבת הנתון (טענה 1)
4pq = 192כפל שני האגפים של טענה 3 ב־4
5q = 28 − pהעברת אגף (מטענה 2)
6p(28 − p) = 192הצבת טענה 5 בטענה 4
7p² − 28p + 192 = 0פתיחת סוגריים והעברת אגפים (מטענה 6)
8(p − 12)(p − 16) = 0פירוק טרינום: 12 ו־16 הם שני מספרים שסכומם 28 ומכפלתם 192 (מטענה 7)
9p = 12 או p = 16מכפלה שווה אפס אם ורק אם אחד הגורמים שווה אפס (טענה 8)
10p = 16, q = 12 ∎אם p = 12, אז q = 16 (טענה 5), בסתירה ל־p > q (טענה 1); לכן p = 16 ו־q = 28 − 16 = 12 (טענה 5)

סיכום התוצאות

  • סעיף א׳: EFGH מלבן
  • סעיף ב׳: היקף EFGH = p + q, שטחו pq4
  • סעיף ג׳: שטח EFGH = ½ · שטח ABCD
  • סעיף ד׳: p = 16, q = 12
